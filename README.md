# Włoski w podróży

Aplikacja (PWA) do nauki włoskiego dla Polaków, z naciskiem na podróż.

- **Ścieżka podróży**: 18 sytuacji z wyjazdu (bar, restauracja, menu, pociąg, taxi, auto i ZTL, nocleg, plaża, apteka, zwiedzanie, pytanie o drogę, small talk, nagłe wypadki) – wszystkie otwarte od razu, z kartami „Dobrze wiedzieć”.
- **Rozmowy**: symulacje – aplikacja mówi jako kelner, konduktor czy recepcjonista; odpowiadasz wybierając, pisząc albo mówiąc.
- **Rozmówki offline**: wyszukiwarka, ulubione i tryb „Pokaż” (duży napis dla kelnera lub kierowcy).
- **Dekoder menu**, **słuchanie „z życia”** (perony, godziny, opóźnienia, ceny), wymowa (spółgłoski podwójne, gli, gn), rodzajniki il/lo/la.
- Dalsza ścieżka A2–C2, trening z automatycznym sprawdzaniem (SM-2), dialogi z shadowingiem, gramatyka kontrastowa, dyktando.

Budowanie: `python build.py` → `Wloski_w_podrozy.html` (jeden plik) i `docs/` (GitHub Pages / instalacja na telefonie).
